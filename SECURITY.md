# Security

This tool handles Gmail OAuth tokens, resumes, and recruiter contact details. None of that belongs in the repo, and `.gitignore` excludes the usual files (`credentials.json`, `token.json`, `.env`, `*.pdf`, `*.db`, `data/`).

If you find a way the tool could leak credentials or personal data, or send an email without approval, please don't open a public issue. Report it privately through [GitHub security advisories](https://github.com/RottenBanana420/jobright-outreach-agent/security/advisories/new).
